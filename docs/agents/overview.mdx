Anarlog gives agents local access to meeting context through the `anarlog` CLI and the local MCP server. Both read the database on your computer, keep reads bounded, and can stage proposals for human review. Nothing is uploaded to an Anarlog server.

| Transport | Choose it when | Output |
| --- | --- | --- |
| CLI | The agent has shell access on your computer | JSON with `--json` |
| Local MCP | The agent supports a local MCP server over stdio | Structured tool results and contextual resources from your database |

Both transports come from the same `anarlog` executable. See [CLI installation](/installation).

## Recommended agent flow

1. Use local MCP, or check local CLI readiness with `anarlog --json doctor`.
2. List recent meetings or search by a short title fragment.
3. Use a returned meeting ID. Never infer or invent one.
4. Fetch the meeting detail before requesting transcript text.
5. Fetch recurring history only when earlier meetings are relevant.
6. Read transcript pages only until the task has enough evidence.

Report database errors instead of hiding them.

## Freshness

Local reads work offline and reflect the database on your computer. Report freshness only when an interface provides it. A meeting's `updated_at` records a content change. If freshness matters and cannot be verified, say it is unknown.

## Safety boundary

Agents should use an Anarlog interface, not SQLite. The supported interfaces apply Anarlog's rules for canonical notes, generated summaries, excluded participants, recurring meetings, and transcript text.

Meeting reads stay bounded. An agent cannot apply a note or summary change. It can stage a proposal with CLI `proposals` commands or the local MCP `propose_*` tools. A human reviews the unified diff in the desktop app and applies or declines it. CLI export can create a separate file; replacing a file requires `--force`.

An agent can also import a recording with CLI `meetings import` or the MCP `import_recording` tool. The desktop app must be open, and it transcribes the audio with your configured Transcription provider.
