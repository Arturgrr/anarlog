The Anarlog skill teaches agents a single workflow across the local MCP server and the `anarlog` CLI:

1. Use local MCP, or check CLI readiness with `anarlog --json doctor` and read with `anarlog --json meetings --source local list`.
2. Resolve meeting IDs from search results.
3. Fetch meeting detail before transcript text.
4. Keep transcript reads bounded and never access SQLite directly.
5. Stage edits as proposals for human review.

## Sources

- Repository package: [`skills/anarlog`](https://github.com/Arturgrr/anarlog/tree/main/skills/anarlog)
- Self-contained copy: `docs/skill.md`, generated from the package

The repository package adds references for setup, CLI commands, MCP tools, and errors.

## Install from the desktop app

Open **Settings → Developers → Agent skills**. Choose **Add skill to…** and pick a detected agent, or choose **Install to all agents**. Anarlog copies the skill bundled with the running app into that agent's skills directory.

The desktop app detects Claude Code, Codex, Cursor, and OpenCode when their configuration directory exists on your computer.

The skill uses the local CLI and MCP server. [Install the Anarlog CLI](/installation) and [configure local MCP](/agents/mcp) as well.

## Install manually

For a filesystem-based agent, copy the complete `skills/anarlog` directory from a clone of the repository into that agent's skills directory. Keep the directory name `anarlog` so relative reference links continue to work.

The repository also contains an agent plugin in `agent-plugins/anarlog` that bundles the skill and a local MCP configuration running `anarlog mcp`. Load it from a clone of the repository, for example in Claude Code:

```bash
claude --plugin-dir ./agent-plugins/anarlog
```

<Note>
  Agent skill locations vary by client. Follow your agent's skill installation instructions rather than copying only `SKILL.md`.
</Note>

The contributor skills under `.agents/skills` are internal repository workflows. They are not part of the public Anarlog skill.
