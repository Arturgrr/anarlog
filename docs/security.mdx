Anarlog is local-first and open source. You can review every component in the [repository](https://github.com/Arturgrr/anarlog).

## What stays true in the product

- Meeting notes live on your computer in a local SQLite database. There is no Anarlog account, server, or cloud copy.
- Anarlog does not add a bot to Zoom, Google Meet, or Microsoft Teams.
- Anarlog sends no usage analytics. Meeting content leaves your computer only for a hosted provider or integration you configure.
- API keys are stored in your operating system's secure credential store.
- Hosted Transcription and Intelligence providers you configure have their own terms, retention, and training policies.

See [Data, privacy, and retention](/data-and-privacy) for the in-app settings that control audio retention and a fully local meeting.

## Report a vulnerability

Use [private vulnerability reporting](https://github.com/Arturgrr/anarlog/security/advisories/new) on GitHub to open a security advisory.

<Warning>
  Do not open a public GitHub issue for a security vulnerability. Use private reporting so it isn't disclosed before a fix ships.
</Warning>
