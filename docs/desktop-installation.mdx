Desktop builds are published on [GitHub Releases](https://github.com/Arturgrr/librelog/releases). Prebuilt packages are currently available for macOS. On Linux and Windows, [build Librelog from source](#build-from-source).

## Choose the right build

| Platform | Build | Notes |
| --- | --- | --- |
| macOS | Apple Silicon DMG | For Macs with an M-series chip. Requires macOS 15 or later. |
| macOS | Intel DMG | For Intel-based Macs. Requires macOS 15 or later. |
| Linux | Build from source | Linux support is in beta. |
| Windows | Build from source | Windows support is in beta. |

On a Mac, open **Apple menu → About This Mac** if you do not know whether it uses an Apple or Intel chip.

## macOS

1. Download the DMG that matches your Mac from the [latest release](https://github.com/Arturgrr/librelog/releases).
2. Open the DMG and move Librelog to **Applications**.
3. Open Librelog (see below) and follow the setup screen.
4. Allow microphone, system audio, and calendar access when you want to use those features.

The macOS builds are not notarized by Apple, so macOS blocks the first launch. To open Librelog anyway, use either method:

- In Finder, right-click (or Control-click) Librelog in **Applications**, choose **Open**, then confirm **Open**.
- Or remove the quarantine attribute in Terminal:

  ```bash
  xattr -dr com.apple.quarantine /Applications/Librelog.app
  ```

You only need to do this once per installed version. Librelog checks GitHub Releases for new versions.

## Build from source

Install Node.js 22, the pnpm version pinned in the repository's `package.json`, and the Rust toolchain pinned in `rust-toolchain.toml`. On Debian or Ubuntu, `scripts/setup-linux-tauri.sh` installs the system libraries Tauri needs.

```bash
git clone https://github.com/Arturgrr/librelog.git
cd librelog
pnpm install
pnpm -F @anlg/ui build
pnpm -F @anlg/desktop tauri build --config '{"bundle":{"createUpdaterArtifacts":false}}'
```

Updater artifacts are only produced by release builds, which need the project's signing key. The build prints the paths of the packages it creates for your platform. The first native build takes a while.

### Linux black window

On Wayland with an NVIDIA GPU, if the window is black or only audio plays, launch with:

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 librelog
```

If the window is still black, also disable compositing:

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 WEBKIT_DISABLE_COMPOSITING_MODE=1 librelog
```

Current builds apply the DMA-BUF workaround automatically. Set the variables yourself only if a black window remains.

## Platform differences

- Apple Calendar and Apple Reminders integrations are available on macOS.
- Soniqo, Apple Speech, and BYO-model on-device transcription require Apple Silicon. Apple Speech also appears only when a compatible Mac running macOS 26 reports the required system assets. On other systems, configure a local Deepgram-compatible server or a provider with your own API key. See [how to use on-device models](/help#use-on-device-models) and [local models for hour-long calls](/help#local-model-hour-long-calls).
- Windows and Linux support are in beta. Include your operating system and Librelog version when you report a platform-specific problem.

When installation is complete, continue to [Your first meeting](/quickstart). If the app does not open or cannot capture audio, see [Troubleshooting](/troubleshooting).
