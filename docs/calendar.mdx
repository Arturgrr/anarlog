---
title: "Connect a calendar"
description: "Bring upcoming meetings from Apple Calendar into Librelog and start them from one place."
---

On macOS, Librelog reads events from Apple Calendar, which includes the calendar accounts already connected to your Mac. Open **Calendar** in the sidebar and enable the calendars you want Librelog to show. Connected events appear in the calendar and timeline.

Librelog uses calendar events for titles, times, participants, reminders, and meeting links. It does not add a bot to your calls, and it does not create, edit, or delete calendar events.

## Apple Calendar

1. Open **Calendar** in the sidebar and choose **Apple Calendar**.
2. Allow Calendar access when macOS asks.
3. Enable the calendars you want to see.

If access was denied, open **Settings → Permissions** in Librelog. Use **Open** beside Calendar to change the macOS permission.

To see events from another calendar service, add that account to the macOS Calendar app first.

## Use calendar reminders

A reminder for an event with a meeting link offers **Join & record**. This opens the meeting and starts listening. Use the arrow beside that action and choose **Open meeting** to join without starting a recording.

For an event without a meeting link, the reminder offers **Start recording**. Keep Librelog running and allow microphone and system-audio access before recording.

## File meeting notes into folders

Open a calendar event and choose **Add to folder** to file its note. After filing a recurring meeting, choose **Auto-add** to put future meeting notes in the same folder. Open the event's folder menu to choose **Change auto-add folder** or **Stop auto-add**. Moving one meeting's note does not change the rule for future meetings.

## Manage or delete calendar data

To control which calendars appear in Librelog, open **Calendar**, expand the provider, and turn individual calendars on or off.

To disconnect Apple Calendar:

1. Open **Calendar**.
2. Hover over or right-click **Apple Calendar**.
3. Open **•••** and choose **Disconnect**.

This resets Librelog's macOS Calendar access and removes Apple Calendar events from active views. Your notes remain.

To permanently remove calendar-derived data retained on a Mac, you currently need to remove all local Librelog app data from that Mac:

<Warning>
  This deletes Librelog's entire local database on that Mac, not just calendar data — including notes, memos, summaries, and settings that have not been exported. Export anything you want to keep first.
</Warning>

1. Export anything you want to keep, then quit Librelog.
2. In Finder, choose **Go → Go to Folder**.
3. Move any of these folders that exist to Trash:
   - `~/Library/Application Support/librelog`
   - `~/Library/Application Support/com.arturgrr.librelog`
4. Empty Trash before reopening Librelog.

This removes Librelog's local database and settings on that Mac, including cached calendar data and event context stored with local records. It can also remove other Librelog data stored in those folders. It does not delete files you exported.

If events are missing, refresh the calendar list, confirm the calendar is enabled, and check **Settings → Permissions → Calendar**.
