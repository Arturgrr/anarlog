---
title: "Use Librelog offline"
description: "Prepare local transcription and intelligence models before working without a network connection."
---

Librelog can record meetings and manage notes without an internet connection. To transcribe, summarize, and chat offline, configure local models before you disconnect.

## What works without the internet

- Create and edit notes.
- Record and play meeting audio.
- Export memos, summaries, and transcripts already on your computer.
- Transcribe with a downloaded Local model or a BYO-model `.bin` or `.gguf` file on an Apple Silicon Mac, Windows x86_64, or Linux x86_64 or ARM64; with Soniqo on an Apple Silicon Mac; or with Apple Speech when available on macOS 26.
- Generate summaries and chat with LM Studio, Ollama, Unsloth, or eligible Apple Intelligence.
- Use the local CLI and MCP server.

Hosted Transcription and Intelligence providers, model downloads, webhooks to remote endpoints, and update checks need a network connection.

## Prepare offline transcription

1. Open **Settings → Transcription**.
2. Choose a provider under **On this computer**:
   - **Local models**: download the model marked **Best for your languages**, or another one that covers them.
   - **Soniqo** on an Apple Silicon Mac: download a Soniqo model.
   - **Apple Speech**, if it appears: add the supported language in macOS System Settings.
   - **BYO-model**: choose **Choose a .bin or .gguf model** to use a whisper.cpp `.bin` or GGUF `.gguf` file you already downloaded.
3. Select the model under **Model being used**.
4. Run a short test recording before going offline.

The model's **Live** or **After recording** label tells you when text will appear. On-device model availability depends on your computer and the current Librelog release; on Windows and Linux, Librelog is [built from source](/desktop-installation#build-from-source). See [Local models](/models-and-providers#local-models) for each model's languages and license.

## Prepare offline summaries and chat

Use [LM Studio](https://lmstudio.ai/download), [Ollama](https://ollama.com/download), or [Unsloth](https://unsloth.ai/docs/desktop) as your local Intelligence provider. Download the model in advance, start the local server, and select that model in **Settings → Intelligence**.

Librelog must be able to reach the local server while you work. The server can run on the same computer without internet access.

On an eligible Mac running macOS 26 or later, you can instead select the experimental **Apple Intelligence → System Language Model** after its system model finishes downloading.

## Check that nothing uses a hosted provider

Before a sensitive meeting, confirm both selections:

- **Settings → Transcription → Model being used** points to an on-device model.
- **Settings → Intelligence → Model being used** points to LM Studio, Ollama, Unsloth, or Apple Intelligence.

Choosing a local model for only one setting does not make the other setting local. See [How can I use on-device models?](/help#use-on-device-models) for each transcription path, [Models and providers](/models-and-providers) for the current model list, and [Data, privacy, and retention](/data-and-privacy) for what each provider receives.
