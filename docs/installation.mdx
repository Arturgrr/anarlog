## Current availability

The `librelog` executable includes both the CLI and the local MCP server. Install it from the desktop app or build it from source.

<Warning>
  Homebrew, standalone release binaries, and package-manager distribution are not available. Do not rely on those channels.
</Warning>

## Install from the desktop app

Open **Settings → Developers** and select **Install** (or **Reinstall**) beside **Librelog CLI**. Release builds copy the bundled CLI onto your PATH.

| Platform | Installed command | Path |
| --- | --- | --- |
| macOS | `librelog` | `~/.local/bin/librelog` |
| Linux | `librelog` | `~/.local/bin/librelog` |
| Windows | `librelog` | `%LOCALAPPDATA%\Librelog\bin\librelog.exe` (added to your user PATH) |

On macOS and Linux, add `~/.local/bin` to `PATH` if your shell cannot find `librelog`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

On Windows, open a new terminal after installing so the PATH update applies.

<Note>
  A desktop app you built yourself may not include the CLI. Use [build from source](#build-from-source) instead.
</Note>

## Build from source

To build the CLI yourself:

```bash
git clone https://github.com/Arturgrr/librelog.git
cd librelog
cargo install --locked --path apps/cli
librelog --version
```

`cargo` installs the executable into its configured binary directory, normally `~/.cargo/bin`. Add that directory to `PATH` if your shell cannot find `librelog`.

## Connect to local data

By default, the CLI looks for `librelog/app.db` in your operating system's application-data directory. It also recognizes legacy Librelog locations.

Open the desktop app once so it can create the database. After that, the CLI and local MCP server work while the app is closed.

For a custom database location, pass a global option or environment variable:

```bash
librelog --db-path /path/to/app.db --json meetings list
LIBRELOG_DB_PATH=/path/to/app.db librelog --json meetings list
```

If you have an Librelog data directory containing `app.db`, use:

```bash
librelog --base /path/to/librelog-data --json meetings list
```

The CLI opens the database in read-only query mode for meeting reads. Proposal create and decline commands, `meetings import`, and `librelog mcp` open the same file for writes so they can stage, discard, or queue work. They do not create a database or run migrations.
