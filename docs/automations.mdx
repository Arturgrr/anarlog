---
title: "Automate meeting follow-up"
description: "Export every meeting as Markdown when it ends."
---

Automations run repeatable work when a meeting ends. They write local Markdown files, so they need no account or connected service.

## Use the starter

Open **Automations** and choose **Export every meeting as Markdown** from the sidebar. It writes the memo, summary, and transcript to a local file.

1. Select the starter.
2. Choose the export folder.
3. Review the trigger, source content, and result preview.
4. Click **Save & enable**.

An enabled starter runs after a meeting ends and the content it needs is ready. Disable it when you want to keep the setup without running it.

## Check whether it ran

The automation detail shows whether it is enabled and the result of its last run. A failed run includes a short error. Confirm that the chosen folder still exists and is writable.

## Choose Markdown export content

In a Markdown export action, choose any combination of **Memo**, **Summary**, **Transcript**, and **Collect action items**. Keep at least one section selected.

Leave **Filename** blank to use the meeting date and title, or enter a pattern such as `{date} {title}.md`. **Include meeting ID** adds a short ID suffix to distinguish similarly named meetings. Anarlog refuses to overwrite a file belonging to a different meeting or an unrelated file; choose another name if an export reports a collision.

These options belong to desktop Automations. CLI `meetings export` still exports a complete meeting and uses the output path you provide; it does not accept these automation settings.

## Build a custom workflow

Click **+** in the Automations sidebar to start a workflow:

1. Choose when it should run: after the meeting summary is ready, or after the meeting ends.
2. Add a Markdown export action and configure its folder and content.
3. Click **Save & enable**.

Enabled custom workflows run automatically, the same way the starter does. Chat on the right can still help you refine the workflow; it is not required to make the automation run.

Anarlog must be open to run a workflow. It does not backfill older notes or queue runs while the app is closed.

To send meeting events to your own service instead, use [webhooks](/reference/webhooks).
