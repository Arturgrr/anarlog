## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-runtime-status`
- `allow-list-models`
- `allow-models-dir`
- `allow-download-model`
- `allow-cancel-download`
- `allow-delete-model`
- `allow-is-model-downloading`
- `allow-ensure-server`
- `allow-stop-server`
- `allow-server-state`
