## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-screen-recording`
- `allow-request-screen-recording`
- `allow-open-screen-recording-settings`
- `allow-start`
- `allow-stop`
- `allow-finalize`
- `allow-cancel`
- `allow-set-ink-mode`
- `allow-status`
- `allow-set-retention`
- `allow-annotations-dir`
- `allow-latest`
