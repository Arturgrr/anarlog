## Note types

- **Group your notes.** Open **Settings → Note types**, next to **Automations**, to add types such as a class or a client, and subtypes under each one, such as a subject or a recurring meeting. Rename or delete them there.
- **Set a note's type** from **Meeting info** in the note's **•••** menu, or when you create the note. **Subtype** appears once you choose a type. Type a name that doesn't exist yet and choose **Create "…"** to add it without opening Settings.
- Deleting a type also deletes its subtypes. Notes that used them show **No type**; nothing else in them changes.

## Assign speakers

- **Name every speaker at once.** After a meeting, choose **Assign speakers…** from the note's **•••** menu. Each speaker gets a row with how many words they said and a sample of what they said. Click **Choose person** on a row, pick someone, and click **Apply**.
- Only the rows you changed are saved. When a note has more than one recording, each row says which **Recording** it comes from.
- **Bring a split voice together.** If one person was split into two speakers, choose the same person for both rows.

## Automations

- **Run for one type of note.** Under **Applies to**, keep every note or choose a note type and, if you like, a subtype. Workflows you saved before keep running for every note.
- **After every speaker is named** is a new trigger. It runs once per note, when you name its last unnamed speaker in the transcript or in **Assign speakers…**.
- **New actions:**
  - **Use a summary template** picks the template for summaries of the notes the workflow applies to. It is available for workflows that run **After the meeting ends**. A template you choose in the note itself still comes first.
  - **Regenerate the summary** writes the summary again, for example so it uses the names you just gave the speakers. It isn't available for workflows that run **After the meeting summary is ready**.
  - **Move the note to a folder** files the note in one of your Librelog folders.
- **Export each type differently.** Create one workflow per type, each with its own **Export the meeting as Markdown** folder and content.

## Name a note first

- **New notes ask for a name.** Creating a note, with **New Note**, Command/Ctrl+N, Command/Ctrl+Shift+N to record right away, the **File** menu, the Dock or the menu bar icon, opens a small dialog with **Name** and **Type**. Press Enter with the name empty to carry on: Librelog titles the note when it writes the summary, as before.
- **Rename while you record.** The note's title stays in the note header during the meeting and after it, so you can change it at any time. The summary's title follows.
- Recordings you start from a Librelog notification still start right away, without the dialog.

## Fixes

- **Start a new meeting** in the menu bar icon created a note without recording. It now starts the recording, after the **New recording** dialog.

## Known limitations

- Set a note's type before its meeting ends: a workflow that runs **After the meeting ends** checks the type when it runs, so a type added later doesn't match.
- Voices that Librelog names for you from **Remember speakers** don't count as naming a speaker, so they don't start **After every speaker is named** on their own.
- Your own microphone row shows **You** in **Assign speakers…** and can't be changed there.
- A summary that already exists keeps its template when it is regenerated, even if a workflow now chooses another one.
- Note types, **Assign speakers…**, the new automations and the new note dialog have been checked with automated tests, but not yet on a Mac by the project.
- Librelog is not notarized by Apple yet. The first launch needs **Open Anyway** in **System Settings → Privacy & Security**.
- Librelog needs a Mac with Apple silicon (M1 or later).
