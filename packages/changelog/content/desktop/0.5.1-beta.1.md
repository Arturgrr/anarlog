## Start a meeting from the menu bar

- **Start a new meeting** in the menu bar icon now starts recording right away, without the **New recording** dialog and without bringing Librelog to the front. It creates an untitled note and records it in the background; the menu bar icon animates while it listens, and the floating bar appears if you turned it on.
- When you open Librelog, the note being recorded is the one you see.
- If a recording is already running, the item stays unavailable, as before.
- Every other way to create a note, including Command/Ctrl+N, Command/Ctrl+Shift+N, the **File** menu and the Dock, still opens the dialog.

## Rename and set the type later

- **Right-click a note in the sidebar** and choose **Rename and Set Type…** to change its **Name**, **Type** and **Subtype** in one dialog. It works while the note is being recorded, and the menu bar title follows the new name.
- Only what you changed is saved. Leave the name empty to make the note untitled again; Librelog titles it when it writes the summary.
- A locked note asks you to unlock it first.

## Known limitations

- If Librelog was locked with **Lock app** since it started and you never unlocked it, **Start a new meeting** opens the window instead, and the recording starts once you unlock. The same can happen in the rare case that the window is being reloaded after a crash.
- If the recording can't start in the background, for example because Librelog lacks microphone permission or a transcription model, Librelog opens its window on the new note so you can see why. This can take up to about 30 seconds when the transcription connection never becomes ready.
- These changes have been checked with automated tests, but not yet on a Mac by the project.
- Librelog is not notarized by Apple yet. The first launch needs **Open Anyway** in **System Settings → Privacy & Security**.
- Librelog needs a Mac with Apple silicon (M1 or later).
